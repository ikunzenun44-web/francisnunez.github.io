# Francis Miguel Nunez — Executive Portfolio

This version replaces the "tech dashboard" look with a more executive, polished visual identity.

## Files
- index.html — website structure/content
- styles.css — visual design
- script.js — scroll-reveal interactions
- profile.jpg — Francis's uploaded portrait
- README.md — this file

## How to open
Keep all files in the same folder and double-click `index.html`.

The site uses Google Fonts when internet access is available; it will fall back to system fonts if not.

## Visual direction
Deep navy, warm ivory, muted gold, editorial serif typography, clean sans-serif body text, restrained motion, and an executive-support positioning.

## Source basis
Professional history, capabilities, education, language level, and software/tool experience are based on the user's resume. No unsupported performance metrics have been added.
